# Sahara Wallet Keeper

أريد واجهة تطبيق محفظة الاكترونية 

مع مبدل بروفايلات للمستخدم نفسه 

شريط عليوي

يحتوي مبدل بروفايلات كقائمة منسدلة 

احترافية تعرض إسم المستخدم هل البروفايل افتراضي مع عرض صوره البروفيل ويوجد خيارين ثابتين في نهاية القائمة تسجيل خروج والإعدادات

صفحة الإعدادات تحتوي شريط اسفل الشريط العلوي 

اول أيقونة إعدادات البروفايل يستطيع المستخدم تعري الصورة الاسم والعملة الافتراضية للملف الشخصي 

الصفحة الثانية للتحكم بمظهر التطبيق 

اللون البرايمري من قائمة منسدلة 

وكذلك الخلفية يكون هناك خلفيات افتراضية متحركة مثل المجسمات المترابطة 



الأيقونة الثالثة التحكم بالأجهزة 

تعرض بطاقات الأجهزة مع خيار توثيق وخيار حظر 



الأيقونة الثالثة الجلسات 

كذلك خيارات حظر وتوثيق. 



الأيقونة الرابع 

passkey 

كذلك توثيق وحظر وتجديد 



الأيقونة الرابعة 

الخزنة تعرض الخزنة 

وإعداداتها 

يمكن قفلها أو فتحها 

يمكن تعوغير كلمة السر 



ابقي الصفحة الرائيسية فارغة حالياً
